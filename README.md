# 2026 台灣創價學會總會動態邀請卡｜設計＋網頁整合版

依《2026_Soka_Invitation_Design_Engineering_Handoff.docx》規格完成的可播放版本。
所有畫面（信封、封蠟、五幕插畫、100 主視覺、光帶、資訊頁）都已用 SVG／CSS／Canvas 繪製成**設計稿**，
因此在正式素材交付前就能完整預覽與驗收流程；正式素材放入 `assets/` 後會**自動取代**設計稿，不需要改程式。

> 注意：請勿再把原始「工程起始包」解壓覆蓋到本資料夾，會蓋掉整合版的 index.html / styles.css / app.js。
> 原始起始檔備份在 `_starter_backup/`。

## 快速開始
- **最簡單**：雙擊 `start.bat`，會同步資料並自動開啟 http://localhost:8080 。
- 直接雙擊 `index.html` 也能看（資料改讀 `event-data.js` 副本）。
- 修改 `event-data.json` 後，執行 `python tools/sync_event_data.py` 更新副本（`start.bat` 會自動執行）。

## 時間軸（點擊封蠟後約 17 秒）
0–0.8 封蠟發光、碎片散開 → 0.8–2.0 上蓋 3D 翻開、暖光透出 → 2.0–2.8 鏡頭推入、暖光溶接
→ 2.8–12.8 五幕各 2 秒（遠→近、清晰停留、淡出）→ 12.8–14.2 粒子匯聚 100、標語分層浮現
→ 14.3–15.9 100 主視覺停留（仍緩慢推近）→ 15.6–17.3 光帶延展、數字與標語淡出、資訊頁浮現。
各幕之間為疊加式交叉溶接（新幕疊在舊幕上淡入，不露黑底），每幕鏡頭為等速推近，不停頓、不突然加速。

## 已實作的規格要求
- 封蠟只能觸發一次；全程有「跳過動畫」（Esc 也可跳過），立即抵達資訊頁。
- 五幕畫面無文字；畫面說明放在螢幕閱讀器可讀的隱藏清單。
- 無背景音樂、無音效。
- `prefers-reduced-motion`：短淡出後直接進資訊頁。
- 低效能裝置（省流量／核心數 ≤4／記憶體 ≤2GB）：減少粒子、取消模糊濾鏡。
- 動畫結束後網址為 `#info`，重新整理會停在資訊頁；「重播開場動畫」可回到信封。
- 手機優先（100svh、安全區）；桌面主畫面限寬 560px、背景延展。
- GSAP CDN 載入失敗時，點封蠟仍可直接進資訊頁。

## QA 工具
網址加上 `?seek=秒數` 會直接定格在該時間點，例如 `?seek=3.9`（第一幕）、`?seek=13.45`（粒子成形）。
